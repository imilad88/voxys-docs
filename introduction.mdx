## Getting Started

### Build Integrations
Explore our [API Reference](/api-reference/introduction) with three categories of APIs:
- **Application APIs** - Manage accounts, agents, conversations, and contacts
- **Platform APIs** - Administrative control for your installation
- **Client APIs** - Build custom chat interfaces

### Authentication
All API requests require an `api_access_token` header. You can find your token in:
- **User tokens**: Profile Settings > Access Token
- **Agent Bot tokens**: Settings > Integrations > Agent Bots
- **Platform tokens**: Super Admin > Platform Apps
